# Security Policy

## Scope

This repository is a reference setup for local use. It is not a hosted service
and ships no production secrets. Reports are still welcome for:

- flaws in the token validation or certificate binding logic
- configuration that weakens the security properties the README claims
- vulnerable dependencies that Dependabot has not picked up

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting
(**Security** tab, **Report a vulnerability**) instead of opening a public issue.

You can expect a first response within five working days. Once a fix is
released, the report is credited in the release notes unless you prefer
otherwise.

## Supported versions

Only the latest commit on `main` is supported.
